# هوى بغداد · Hawa Baghdad

موقع **مفهوم** لمشروع مطعم بغدادي في الدوحة، قطر.

> **حالة المشروع:** المطعم لم يُفتح بعد. هذه الصفحة تعرض المفهوم
> والهويّة والمائدة المقترحة وتصوّر المكان — بلا عنوان وهمي ولا صور
> لمكان غير موجود. تُحوَّل إلى موقع مطعم عامل عند الافتتاح.

---

## ما الذي يميّز هذا الموقع تقنياً

### محرّك ضوء الشناشيل

الشُنشول هو النافذة البغداديّة الخشبيّة المحفورة بزجاجها الملوّن،
ووظيفتها الأصليّة أنها **تُرشّح الضوء**: فتدخل الشمس شفرات ملوّنة
تتحرّك على الأرض طول النهار.

الموقع يبني على هذا محرّكاً واحداً:

```
التمرير  =  مرور النهار
```

متغيّر CSS واحد اسمه `--sun` قيمته بين ٠ و١ يحرّكه التمرير، ومنه
تُشتق حرارة اللون وزاوية شفرات الضوء وشدّتها وتدرّج السماء. فالصفحة
لا «تتحرّك عناصرها» فقط، بل **يتغيّر وقتها**: تبدأ فجراً بارداً
وتنتهي ليلاً دافئاً حول الجمر.

لماذا هذا أفضل من تأثيرات متفرّقة؟ لأنه منظومة واحدة: كل التدرّجات
تتبع متغيّراً واحداً، فتتحرّك معاً ومتناسقة، ويكفي سطر واحد لتعديل
مزاج الصفحة كلها.

### صفر أصول خارجيّة

كل زخرفة ورسم في هذا الموقع **مرسوم متجهيّاً خصّيصاً له**: الشناشيل،
النخيل، موج دجلة، الطابوق الفرشي، التنّور، أيقونات الأطباق التسع،
وحبيبات الفيلم.

| النتيجة | القيمة |
|---|---|
| حجم الموقع كاملاً | أقل من ٢٠٠ كيلوبايت |
| صور نقطيّة (raster) | صفر |
| مخاطر حقوق | صفر |
| أُطُر عمل (frameworks) | صفر |
| خطوة بناء (build step) | لا توجد — HTML و CSS و JS عاديّة |

وهذا قرار مقصود لا اضطرار: المطعم لم يُفتح، فصور طعام مولَّدة بالذكاء
الاصطناعي تُظهر طعاماً **ليس طعام المطعم** — وهذا وعدٌ لا يمكن الوفاء
به يوم الافتتاح. الرسم المتجهيّ صادق: يقول «هذا تصوّر» لا «هذه صورة».

### تقنيات أخرى

- **كشف مربوط بالتمرير** عبر `animation-timeline: view()` الأصليّة
  حيث تتوفّر — تعمل على خيط المُركِّب فلا تتعثّر — ومراقِب
  `IntersectionObserver` بديلاً.
- **لفّ أفقي مثبَّت** لعرض بغداد، بإشارة `translateX` صحيحة في RTL
  (انظر التحذير أدناه).
- **اهتزاز حرارة** بمرشّح SVG حقيقي (`feTurbulence` + `feDisplacementMap`)
  مطبَّق على طبقة الهواء لا على الصور، فتبقى الصور حادّة.
- **مشهد مثبَّت** للمسكوف: الصورة تتبع الخطوة المقروءة.
- **تحسين تدريجي كامل:** كل المحتوى في HTML. لو فشل تحميل
  الجافاسكربت تبقى الصفحة مقروءة ومتنقّلة بالكامل.

```
index.html              الصفحة العربيّة (RTL) — كل المحتوى هنا
en/                     النسخة الإنجليزيّة
assets/css/
  tokens.css            ◀ كل قيمة بصريّة في الموقع. ابدأ من هنا.
  base.css              إعادة التهيئة والطباعة
  layout.css            الترويسة والأقسام والأزرار والذيل
  cinematic.css         الطبقة السينمائيّة ومحرّك الضوء
assets/js/app.js        التحسين التدريجي فقط
assets/img/*.svg        زخارف متجهيّة أصليّة
brand/                  ◀ ملفّات الهويّة تُرفع هنا (انظر brand/README.md)
docs/                   الحقوق والهويّة والـ SEO
tools/                  أدوات التحقّق
```

### تعديل الألوان والخطوط

**كل** قيمة بصريّة في الموقع تُشتق من `assets/css/tokens.css` وحده.
لا ألوان ولا قياسات مكتوبة مباشرةً في أي ملف آخر. لتطبيق هويّة
جديدة، حرِّر كتلة `BRAND PALETTE` في ذلك الملف — ويتبعها الموقع كله.

الألوان الحاليّة **مبدئيّة**، مبنيّة على عمارة بغداد القديمة
(طابوق فرشي أصفر، خشب شناشيل، زجاج ملوّن، ليل دجلة) وليست مأخوذة
من بروفايل هويّة معتمد.

لا يحتاج الموقع أي تثبيت:

```bash
python3 -m http.server 8000
# ثم افتح http://localhost:8000
```

> والمسارات النسبيّة تتصرّف تصرّفاً مختلفاً على بروتوكول الملفّات.

## التحقّق

```bash
# إشباتُ اتجاه اللفّ الأفقي + قياس تباين الألوان بمعيار WCAG
chrome --headless --dump-dom tools/rtl-proof.html

# فحص أبعاد أي صورة قبل قراءتها
python3 tools/imgguard.py probe <file>
```

`tools/rtl-proof.html` ليس اختباراً شكليّاً. يقيس شيئين لا يمكن
الحكم عليهما بالنظر في بيئة بلا خطوط عربيّة:

1. **أي إشارة `translateX` تكشف المحتوى في RTL** — بالقياس لا بالرأي.
2. **نسب التباين** مقابل معيار WCAG — بالحساب لا بالعين. وقد كشف
   فعلاً أن الذهب على الرمل يعطي ٢٫١٤:١ (الحدّ ٤٫٥:١)، فاستُبدل
   بالبرونز `#8A4A12` الذي يعطي ٦٫٠٩:١.

## ⚠ تحذيرات لمن يكمل العمل على هذا المستودع

### ١ — إشارة اللفّ الأفقي في RTL

في صفحة RTL يمتدّ المحتوى الزائد في حاوية flex إلى **اليسار**. فالكشف
عنه يتطلّب `translateX` بقيمة **موجبة**. القيمة السالبة تدفعه بعيداً
عن الشاشة فيبدو أن «لا شيء يتحرّك».

الإشارة في `app.js` مشتقّة من اتجاه المستند ولا تُكتب يدوياً:

```js
var sign = isRTL ? 1 : -1;
```

### ٢ — حدّ ٢٠٠٠ بكسل

قراءة صورة يتجاوز أيٌّ من بُعديها ٢٠٠٠ بكسل تُفشل العمليّة **بعد**
انتهاء العمل كله، فيُهدر الوقت والرصيد. افحص أبعاد كل صورة مجهولة
المصدر قبل قراءتها بـ `tools/imgguard.py probe`.

للتخطيطات المطبوعة: أقصى DPI آمن = `2000 ÷ أطول بُعد بالبوصة`.
فصفحة ٤×١٢ إنش حدّها ١٦٦ DPI، لا ٣٠٠.

### ٣ — كاش GitHub Pages

كاش GitHub Pages يُظهر نسخاً قديمة فيبدو أن الإصلاحات لم تُنفَّذ.
لذلك يحمل كل أصل محلّي رقم إصدار (`?v=N`) في `index.html` —
**زِد هذا الرقم في كل دفعة تعديل**.

ولمراجعة أي تغيير: افتح الرابط بمعامل استعلام جديد
(`?v=5`) أو في نافذة تصفّح متخفّي. عنوانٌ مختلف يتجاوز كاش
صفحة HTML نفسها، وهو ما لا تحلّه أرقام إصدار الأصول.
